Списки

Нумерованый список — Ordered list

Создает дескриптором <ol>.

  1. элемент 1;
  2. элемент 2;
  3. элемент 3;
  4. элемент 4;
  5. элемент 5;

Маркерованный список — Unordered list

Создает дескриптором <ul>.

  • элемент 1;
  • элемент 2;
  • элемент 3;
  • элемент 4;
  • элемент 5;

Желементы список — listItems

Как в нумерованном, так и в Мерверовнным списке элементы создаются дескриптором <li>.

Список оприделений ― Definitions List

создается дескриптор <dl>. что означает Desription list.
Каждый элемент кода описывается двумя дискрипторам: <dt> — Desription Term и <dd> — Desription Details

Нумерованный список
Каждый эелемент такого списка имеет точный порядоковый номер;
Маркерованый список
Каждый эелемент такого списка обозначен каким либо символом;
Список определений
Каждый эелемент такого списка ввщдит понятие и дает ему определение;
